Float Apps - แอปหน้าต่างลอย (ไม่มีโฆษณา)

วิธีที่ 1: Android Studio (บนคอม)
  1. เปิดโฟลเดอร์นี้ด้วย Android Studio แล้วรอ Sync
  2. เมนู Build > Build Bundle(s) / APK(s) > Build APK(s)
  3. ไฟล์อยู่ที่ app/build/outputs/apk/debug/app-debug.apk

วิธีที่ 2: GitHub Actions (ไม่ต้องใช้คอม)
  1. สร้าง repo บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ .github)
  2. แท็บ Actions > Build APK > Run workflow
  3. เสร็จแล้วโหลดไฟล์ FloatApps-debug-apk จากหน้า run

ติดตั้ง: เปิด "ติดตั้งจากแหล่งที่ไม่รู้จัก" แล้วแตะไฟล์ APK
ครั้งแรกที่เปิดแอป ให้สิทธิ์ "แสดงทับแอปอื่น"

อัปเดต v1.1: ถ้าติดตั้งทับเวอร์ชันเก่าไม่ได้ ให้ถอนการติดตั้งเวอร์ชันเก่าก่อน


อัปเดต v1.8 (เบราว์เซอร์)
  - ปุ่ม ☰ ในแถบแท็บ: ปักหมุดหน้านี้ (📌), เก็บบุ๊กมาร์ก (★), เปิดรายการไฟล์ที่โหลด
  - หมุดที่ปักไว้แสดงเป็นแถบใต้แท็บ แตะเพื่อเปิด/สลับไปแท็บเดิม
  - ดาวน์โหลดไฟล์ (DownloadManager มีแจ้งเตือน) และกดค้างที่รูปเพื่อ "บันทึกรูป"
  - อัปโหลดไฟล์ (เว็บที่มีปุ่มเลือกไฟล์ จะเปิดตัวเลือกไฟล์ของระบบ)
  - โหมดประหยัดสเปค: แท็บเกิน 3 แท็บจะถูก "แช่แข็ง" (คืนหน่วยความจำ) แล้วโหลดกลับเมื่อแตะ,
    ย่อหน้าต่างแล้วหยุด JS/ตัวจับเวลา (ยกเว้น YouTube), คืนหน่วยความจำเมื่อเครื่องเริ่มเต็ม
  - กันแอปหยุดทำงาน: จำหน้าต่าง/แท็บที่เปิดอยู่ ถ้าระบบปิดแอปจะเปิดกลับให้อัตโนมัติ,
    หน้าเว็บที่ทำให้ค้างซ้ำจะไม่ถูกรีโหลดวนไม่สิ้นสุด, บันทึกข้อผิดพลาดล่าสุดที่ files/crash.txt
  ข้อจำกัด: ลิงก์ดาวน์โหลดแบบ blob:/data: ยังไม่รองรับ
